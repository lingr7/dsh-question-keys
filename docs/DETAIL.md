# 提问卡方向键操作

DSH 的提问卡（`ask_user_question` / 计划评审）默认把焦点留在输入框，选项只能靠鼠标点，遥控器按不出来。这个插件在提问卡出现时接管焦点，让一屏按键完成整组回答。

## 按键

| 键 | 行为 |
| --- | --- |
| ↑ / ↓ | 在选项之间移动（首尾循环），焦点框会跟着走 |
| 确定（Enter） | 选中当前选项。单选会直接跳到下一题；多选是「切换勾选」，可以反复按 |
| → / ← | → 跳到右下角「下一步 / 提交」按钮；← 回到第一个选项 |
| 返回（Esc） | 不拦截，交给 dsh-approval-hotkeys 处理成「放弃整组」 |
| 输入法 / 打字 | 焦点在自由文本框里时插件完全不插手，语音照常输入 |

## 为什么需要它

提问卡的选项按钮自带一个 `Enter` 处理：按下就提交整组答案，而不是选中当前项。插件在捕获阶段先接住 `Enter`，改成真正的点击，才符合「确定 = 选中」的直觉。同时给卡片里的可聚焦元素加了描边，遥控器操作时能看清焦点停在哪。

## 范围

- 只处理 `[data-question-key]` 面板；审批卡（`[data-approval-key]`）和计划评审卡（`[data-plan-review-key]`）的 Enter/Esc 由 dsh-approval-hotkeys 负责，本插件只给它们加焦点描边。
- 不注册任何全局快捷键，不占用键位，因此不会和 `Alt+↑/↓` 的会话切换、方向键的翻页/光标移动冲突。
- 卡片消失后把焦点还给输入框，可以直接接着说下一句。
